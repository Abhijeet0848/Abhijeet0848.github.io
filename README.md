- **Dynamic Typewriter Effect:** Live typing animation highlighting my focus areas.

- **Interactive 3D Terminal & Bento Grid:** Hover and tilt effects for an immersive UI experience.
- **Doraemon 4D Magic Pocket Animation:** A fun, interactive CSS/SVG animation where Doraemon pulls out my resume!
- **Projects Showcase:** A clean grid featuring detailed case studies of my academic and personal projects.
- **Responsive Design:** Fully optimized for mobile, tablet, and desktop viewing.
